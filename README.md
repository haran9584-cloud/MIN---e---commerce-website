# MIN---e---commerce-website
A responsive e-commerce web app for men's clothing built with HTML, CSS and Vanilla JavaScript. Features include product listing, add to cart, quantity selector and checkout page.

## ✨ Features

- 🛒 Dynamic product listing fetched from API
- ➕ Add to cart functionality
- 🔢 Quantity selector for each product
- 🧾 Order summary on checkout page
- 💰 Real-time cart quantity update
- 📱 Responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- XMLHttpRequest (XHR) for API calls
- Git & GitHub for version control
